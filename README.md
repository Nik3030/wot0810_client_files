# Правки клиента wot0810

Файлы для клиента World of Tanks **0.8.10**, чтобы играть на сервере wot0810.

## Как поставить и обновлять

1. Скачайте `sync.bat` и положите его в папку игры, рядом с `WorldOfTanks.exe`.
2. Закройте игру и запустите `sync.bat`.

Батник сам скачает нужные файлы, проверит их и заменит изменившиеся.
Запускайте его перед игрой — так всегда будут свежие правки.

Git и что-либо ещё ставить не нужно, батник работает на встроенном в Windows
PowerShell.

## Как вернуть клиент к оригиналу

```
sync.bat restore
```

Оригинальные файлы, которые батник заменил, лежат в `wot0810_backup` в папке
игры и возвращаются на место.

## Что меняется в клиенте

| файл | зачем |
|---|---|
| `res/scripts_config.xml`, `res/loginapp_wot.pubkey` | адрес сервера и его ключ |
| `res/scripts/common/debug_utils.pyc`, `client_hooks.pyc` | точка входа правок |
| `res/scripts/common/marker_matrix.pyc` | маркер союзника не замирает за холмом |
| `res/scripts/common/sniper_stabilizer.pyc` | полная стабилизация прицела, динамическая камера выключена |
| `res/gui/flash/settingsWindow.swf`, `res/gui/scaleform/SettingsDialog.swf` | в настройках нет галочек камеры и стабилизации |
| `res/gui/flash/techtree/*.xml` | премиум-техника отдельным блоком в дереве |
| `paths.xml` | строка `./res` поднимается выше пакетов |

Каждый файл сверяется по SHA-256 из `manifest.txt`. Других файлов игры батник
не трогает.
